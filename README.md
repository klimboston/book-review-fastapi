# Book Review API 📚

Бэкенд-сервис для отзывов и обзоров на книги. Позволяет пользователям регистрироваться, добавлять книги в личную библиотеку и оставлять отзывы с оценками.

## Стек 
* **Python 3.14**
* **FastAPI**
* **SQLModel / SQLAlchemy** (ORM, работа с БД SQLite)
* **PyJWT & Bcrypt** (Безопасность, авторизация и хеширование паролей)
* **UV** (Быстрый менеджер пакетов)
* **pytest** (Тестирование)

## Быстрый запуск через Docker Compose 🐳

В проекте настроен Docker Compose для мгновенного развертывания приложения со всеми настройками и переменными окружения одной командой.

1. Убедитесь, что у вас создан файл `.env` в корне проекта (В нем должны храниться SECRET_KEY, DATABASE_URL и ALGORITHM(для jwt)).
2. Запустите сборку и старт контейнера:
   ```bash
   docker compose up --build
   ```
3. Откройте интерактивную документацию API: `http://127.0.0`
4. Для остановки проекта нажмите `Ctrl + C`.
